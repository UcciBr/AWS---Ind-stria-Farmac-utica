# RELATÓRIO DE IMPLEMENTAÇÃO DE SERVIÇOS AWS

Data: 20/05/2026

Empresa: Abstergo Industries

Responsável: André 

## Introdução

Este relatório apresenta o processo de implementação de ferramentas na empresa Abstergo Industries, realizado por André. O objetivo do projeto é elencar 3 serviços AWS, com a finalidade de diminuir custos imediatos.

## Descrição do Projeto

O projeto de implementação de ferramentas foi dividido em 3 etapas, cada uma com seus objetivos especí­ficos. A seguir, serão descritas as etapas do projeto:

Etapa 1:

* Amazon S3

* Armazenamento seguro e escalável de documentos, backups e dados laboratoriais

* O Amazon S3 foi selecionado para armazenar documentos farmacêuticos, resultados laboratoriais, backups e arquivos regulatórios em nuvem, reduzindo custos com servidores físicos locais e aumentando a segurança e disponibilidade das informações.

Etapa 2:

* Amazon EC2

* Hospedagem e processamento de sistemas corporativos em infraestrutura virtual

* O Amazon EC2 foi implementado para substituir servidores físicos utilizados nos sistemas internos da empresa, permitindo escalabilidade sob demanda, redução de gastos com hardware e menor custo de manutenção da infraestrutura.

Etapa 3:

* AWS Lambda

* Automação de processos e execução serverless

* O AWS Lambda foi utilizado para automatizar processos internos, como envio de relatórios, integração entre sistemas e processamento de dados laboratoriais, eliminando custos com servidores dedicados e reduzindo tempo operacional das equipes.

## ConclusÃ£o

A implementação de ferramentas na empresa *Abstergo Industries* tem como esperado redução de custos operacionais, maior segurança dos dados, automação de processos e aumento da disponibilidade dos sistemas, o que aumentará a eficiência e a produtividade da empresa. Recomenda-se a continuidade da utilização das ferramentas implementadas e a busca por novas tecnologias que possam melhorar ainda mais os processos da empresa.
